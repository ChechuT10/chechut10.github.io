Política de privacidad

Aplicación: Health Sync - Recomposicion Personal
Última actualización: 5 de octubre de 2026

1. Ámbito

Esta aplicación es de uso exclusivamente personal. Su único usuario es su propio desarrollador. No se ofrece al público ni accede a datos de otras personas.

2. Datos a los que accede

Con autorización expresa mediante OAuth de Google, la aplicación accede a los siguientes datos de la cuenta de Google Health del propietario: actividad (pasos, ejercicios, calorías, zonas de frecuencia cardíaca), sueño, métricas de salud (frecuencia cardíaca, variabilidad de la frecuencia cardíaca, saturación de oxígeno, peso, grasa corporal) y nutrición.

3. Finalidad

Los datos se usan únicamente para calcular objetivos nutricionales y generar planes semanales de alimentación y entrenamiento para el propio usuario, y para registrar en su cuenta las comidas y medidas corporales.

4. Almacenamiento

Los datos se guardan en un dispositivo propio situado en el domicilio del usuario. Las copias de seguridad se almacenan cifradas en el almacenamiento personal en la nube del propio usuario.

5. Procesamiento con IA

Resúmenes agregados de los datos se envían a la API de Gemini de Google, contratada en modalidad de pago, bajo cuyas condiciones los datos no se utilizan para entrenar ni mejorar modelos.

6. Cesión a terceros

Los datos no se venden, no se comparten con terceros y no se usan con fines publicitarios. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

7. Revocación y borrado

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions. Los datos almacenados localmente pueden borrarse eliminando la base de datos del dispositivo.
